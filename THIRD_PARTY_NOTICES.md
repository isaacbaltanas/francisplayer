# Third-party notices

Francis Player distributes an unmodified FFmpeg executable through the `ffmpeg-static` npm package.

- Project: FFmpeg
- Website and source code: https://ffmpeg.org/
- Binary provider: https://github.com/eugeneware/ffmpeg-static
- License information: https://ffmpeg.org/legal.html

The bundled executable reports GPL-enabled build options. Francis Player launches it as a separate process and does not link against FFmpeg libraries. The FFmpeg copyright and license notices remain included with the packaged dependency.
